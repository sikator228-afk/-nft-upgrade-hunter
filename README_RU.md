# NFT Upgrade Hunter — стартовый монитор объявлений Getgems

Бот присылает в Telegram новые объявления NFT из указанных коллекций Getgems. Если цена объявления ниже медианы до 20 самых дешёвых объявлений коллекции на заданный процент, сообщение помечается как возможная недооценка.

## Важные ограничения

- Это **монитор новых объявлений**, а не гарантированный поиск всех только что улучшенных Telegram-подарков.
- Для старта укажи адреса коллекций Telegram Gifts, которые хочешь отслеживать. Глобальный список всех коллекций не подставляется автоматически.
- Официальный Getgems Read API по документации требует API-ключ. В официальной документации указана стоимость доступа **10 GRAM в месяц**. Сам запуск GitHub Actions для публичного репозитория бесплатен в пределах условий GitHub.
- Значение «ниже медианы» — только сигнал для ручной проверки. Оно не учитывает комиссии, ликвидность, редкость, историю продаж и возможность быстро перепродать.
- API может менять формат ответа. При ошибках проверь актуальную схему в https://api.getgems.io/public-api/docs.
- Не отправляй боту seed-фразу, приватный ключ или доступ к TON-кошельку. Боту не нужны права на покупку/перевод NFT.

## Что понадобится

1. Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
2. Getgems API key: открой https://getgems.io/public-api и подключись через TON Connect. Проверь стоимость доступа до оплаты.
3. Бесплатный аккаунт GitHub: https://github.com.
4. Адрес одной или нескольких NFT-коллекций Getgems.

## Настройка с iPhone

### 1. Создай Telegram-бота

1. Открой @BotFather.
2. Отправь `/newbot`.
3. Придумай имя и username, заканчивающийся на `bot`.
4. Скопируй токен. Не публикуй его и не отправляй никому.

### 2. Узнай свой Telegram chat_id

1. Открой созданного бота и нажми Start или отправь `/start`.
2. В Safari открой, заменив `TOKEN` своим токеном:

   `https://api.telegram.org/botTOKEN/getUpdates`

3. Найди в ответе `"chat":{"id":123456789...}`. Это твой CHAT_ID.
4. Не пересылай ссылку с токеном. Если токен случайно раскрылся, перевыпусти его через BotFather командой `/revoke`.

### 3. Получи Getgems API key

Открой https://getgems.io/public-api, подключи кошелёк через TON Connect и проверь условия доступа. Не передавай боту seed-фразу. В GitHub добавляется только API key.

### 4. Создай GitHub-репозиторий

1. Открой https://github.com/new.
2. Назови репозиторий `nft-upgrade-hunter`.
3. Для бесплатного использования GitHub Actions выбери **Public**.
4. Создай репозиторий.
5. Добавь файлы из этого архива, сохраняя структуру:
   - `bot.py`
   - `requirements.txt`
   - `.github/workflows/scan.yml`

В приложении GitHub можно создать файл через **Add file → Create new file**. Для папок в имени файла используй полный путь, например `.github/workflows/scan.yml`.

### 5. Добавь секреты

В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь три секрета:

- `BOT_TOKEN` — токен от BotFather.
- `CHAT_ID` — твой числовой chat_id.
- `GETGEMS_API_KEY` — ключ Getgems.

Затем открой **Settings → Secrets and variables → Actions → Variables** и добавь:

- `COLLECTION_ADDRESSES` — адреса коллекций через запятую.
- `DISCOUNT_PERCENT` — например `20`.

### 6. Запусти

Открой вкладку **Actions → NFT listing watcher → Run workflow**. После первого запуска проверь логи и сообщения бота. Дальше GitHub Actions будет запускать сканирование примерно раз в 10 минут; расписание GitHub может задерживаться.

## Как получить адрес коллекции

Открой нужную коллекцию на Getgems в Safari и скопируй адрес коллекции из её публичной страницы/информации. Вставь именно адрес коллекции, не адрес отдельного NFT.

## Как бот оценивает «выгодность»

Он сравнивает цену нового объявления с медианой цен до 20 самых дешёвых объявлений, которые вернул API для этой коллекции. Если цена ниже медианы на 20% или больше, бот добавляет предупреждение. Это грубый фильтр: проверяй редкость атрибутов, историю реальных продаж, комиссии и ликвидность вручную.

## Если не работает

- `401/403`: неверный или неактивный API key / нет доступа.
- `429`: слишком частые запросы; увеличь интервал.
- `No collection addresses`: проверь переменную `COLLECTION_ADDRESSES`.
- Бот молчит: проверь `CHAT_ID`, токен и что ты нажал Start.
- Если API вернул другую структуру данных, посмотри ответ в логах и актуальную схему API.

## Локальный тест (необязательно)

На компьютере или в Python-окружении можно установить зависимости и запустить `python bot.py`. На iPhone удобнее запускать через GitHub Actions.
